# opencore-smbios-switch —— 使用说明

> 给**使用者**看的速查。技术细节在 `SKILL.md` 与 `references/` 里，不用管。

## 怎么用

**直接用自然语言说需求就行**，不用记技能名。也可以手动指定：输入框打 **`/`** → 选 `opencore-smbios-switch`；或点输入框左下角 **`+` → 技能**。

## 说这些话就会触发

| 你想做什么 | 直接这么说 |
|---|---|
| **换机型** | 「换一下 SMBIOS 机型」「我想从 iMacPro1,1 换成 MacPro7,1」「机型要不要换」 |
| **配三码** | 「三码怎么配」「序列号怎么生成」「ROM 填什么」「MLB 是什么」 |
| **iMessage 登录不了** | 「信息登录不了，是不是三码问题」「FaceTime 打不开」 |
| 换完开不了机 | 「换了机型之后卡住开不了机」「卡在 AppleUSBHost」 |
| 判断该不该换 | 「我这个机型在新系统上还支持吗」「不换机型行不行」 |

> **注意分工**：如果你要的是「**审配置 / 补 SSDT / 装驱动 / 升级系统**」，那是另一个技能
> （`opencore-config-audit`）。**那个技能不会替你改机型** —— 换机型只在这里做。

## 你会拿到什么

- **该不该换的判断**：功能收益 / 成本 / 风险三条摆清楚，**能不换就不换**
- **正确的操作顺序**：换机型会和 USB 图、CPU 电源 profile 耦合在一起，
  顺序错了会**直接开不了机** —— 这里给的是验证过的顺序
- **三码方案**：序列号生成 + 三类判据（哪个能用、哪个必须换）+ `ROM` 怎么取
- **救援路径**：改坏了怎么回来

## 三件必须先知道的事

1. **换机型不是「改几个键」** —— 它连带换掉 macOS 想附加的内置 USB 图，与你的 USB 映射合并冲突时会**卡死开不了机**
2. **必须同时重做 CPU 电源数据**，否则换完 CPU 可能被压在低频
3. **改之前先备份 EFI + 备一个能用的 U 盘 EFI** —— 这是唯一的安全网

## 注意

- ★★ **三码（序列号 / MLB / UUID）和 `ROM` 等同于这台机器的 Apple 身份**
  （iMessage / FaceTime 认的就是它们）—— **不要写进任何会公开的地方**（仓库、issue、截图、日志）
- **换码要克制**：社区风控里「脏三码 + 频繁换号」是最典型的触发组合
- 改的是 EFI，会走安全流程（备份 → 校验 → 复验）
